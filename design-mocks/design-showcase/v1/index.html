Overview

画面全体が生きた MapLibre のグローブで、それ以外はすべてその上に浮かぶ半透明のコントロール面。 デザイン言語は dark data console / HUD — 落ち着いた クールスレートの中立色、規律ある白のテキスト階層、そして「ここ / いま」だけに使う単一の暖色アクセント。 地理が常に主役で、UI は隅にまとまり地図と競合しない。

cool-slate neutrals system font / lang=ja rose accent = here / now depth = frosted glass

Colors

色は hue ではなく role（役割） で命名される。chrome の色はすべてトークン経由（領土の塗りはデータ駆動で、ここには含めない）。

Do's & Don'ts

Do

  • role トークン（role-selected / surface-* / text-*）で書く
  • typography role（text-panel-title 等）を使う
  • rose アクセントは選択領土・現在の年だけに使う
  • 浮遊面は必ず frosted（slate + blur + soft shadow）
  • async パネルは loading / empty / error / loaded を明示
  • 全高サーフェスは 100dvh で測る

Don't

  • rose を hover や一般的な強調に浪費しない
  • 領土の塗り（データ）と chrome の色を混ぜない
  • hex や raw Tailwind 原色（gray-* 等）を chrome に書かない
  • role がある意図に raw な text-{size}/font-{weight} を使わない
  • web フォントを足さない（native 日本語描画が壊れる）
  • 重いドロップシャドウを主たる深さの手段にしない
