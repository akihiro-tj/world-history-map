Overview

画面全体が生きた MapLibre のグローブで、それ以外はすべてその上に浮かぶ半透明のコントロール面。 デザイン言語は dark immersive atlas — 夜の天文台 — 落ち着いた クールスレートの地、規律ある白のテキスト階層、そして「ここ / いま」だけに灯す単一の暖色（ゴールド）。 地理が常に主役で、UI はレンズを囲む静かな観測機器のように隅へ退き、地図と競合しない。

cool-slate neutrals system font / lang=ja gold accent = here / now depth = frosted glass

原則 — この6つが全決定を生む

  1. 1. 地図が主役、UI は観測機器 — 暗い地・frosted・退く chrome はここから導かれる
  2. 2. 暖色の一点 =「ここ / いま」 — ゴールドは選択領土と現在年だけ。意味は希少さ
  3. 3. 読むための道具 — 本文は読みやすさ優先。サイズは“種類”を、色は“同じ種類内の主従”を表す（副次は縮めず暗くする）
  4. 4. 選んで探る、入力しない — map と年代ストリップが主たる入力面。フォームは持たず、操作の大半が select なので focus ring が主役の手がかり
  5. 5. 非同期は常に明示 — loading / empty / error / loaded を必ず描く
  6. 6. モバイルは reflow せず re-home — FAB + bottom sheet に再配置

Colors

色は hue ではなく role（役割） で命名し、値は「役割が違えば 見た目も違う」を満たすよう選ぶ。chrome の色はすべてトークン経由（領土の塗りはデータ駆動で、ここには含めない）。

Accent — 唯一の持続する暖色

role-selected は安静時に唯一光る暖色（ゴールド）。選択中の領土 と 現在の年 にだけ使う。天文台の一点の光であり、hover や一般的な強調に浪費すると「いま / ここ」のシグナルが消える。

Status — フィードバック時だけ現れる過渡色

ローディング/フォーカスのシステム青とエラーの赤。いずれも表示中だけ現れて消える過渡色で、安静時の UI に居座らずゴールドのアクセントと競合しない。role-loading と role-focus は同値（#38bdf8）の同じシステム青で、用途だけが異なる（識別の必要がない過渡シグナル）。warning 状態はこのプロダクトに存在しないため warn 色は持たない。

Typography

system font stack のみ（web フォントなし）。階層は weight と size で作り、letter-spacing は使わない。 スケールは意図的に疎で 6 role・本文 1 サイズ。同じ role の中での主従は font を縮めず 色（明度ランプ）で表す — ラベルと値はどちらも 16px で、text-tertiary と text-primary で差をつける。

Do's & Don'ts

上の原則をスキャン可能にしたチェックリスト。ドリフトした画面を捕まえるために使う。

Do

  • role トークン（role-selected / surface-* / text-*）で書く
  • typography role（text-panel-title / text-body 等）を使う
  • ゴールドのアクセントは選択領土・現在の年だけに使う
  • 浮遊面は必ず frosted（slate + blur + soft shadow）
  • async パネルは loading / empty / error / loaded を明示
  • 全高サーフェスは 100dvh で測る

Don't

  • ゴールドを hover や一般的な強調に浪費しない
  • 赤(error)を安静時の UI に居座らせない（過渡的なフィードバック。warning 色は持たない）
  • 領土の塗り（データ）と chrome の色を混ぜない
  • hex や raw Tailwind 原色（gray-* 等）を chrome に書かない
  • 6 role の中間に type role を足さない / 本文を縮めて副次を表さない（色で表す）
  • web フォントを足さない / 重いドロップシャドウを主たる深さにしない
