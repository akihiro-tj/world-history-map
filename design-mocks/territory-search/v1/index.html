territory-search — v1

領土名検索 UI の構造を比較するラウンド。検索はこのプロダクトの 「select-and-explore, never fill-in（原則4）」と緊張するため、どこに置き、いつ現れるか がデザイン適合を左右する。比較軸は「standing chrome をどれだけ足すか」と「地図中央をどれだけ侵すか」。 各案とも 5 状態（idle / loading / results / no-match / error）を明示する（原則5 RemoteData）。

Issue #139 DESIGN.md ← モック一覧

各案上部の状態タブで idle / loading / results / no-match / error を切替（desktop・mobile 同時に反映）。 検索語は全案で「帝国」を共通サンプルとし、構造だけを比べられるようにしている。

control-bar-expand — control bar 統合・展開型

右上 control bar に検索アイコンを 1 つ足す。タップで横に入力欄が展開し、その下に結果ドロップダウンが下りる。 普段は畳まれ、必要時だけ現れる。standing chrome の増分は最小・地図中央は無侵襲で、原則1/4 に最も忠実。

command-palette — コマンドパレット型

⌘K（モバイルは検索 FAB）で scrim 付きの中央オーバーレイを開く。入力が大きく、↑↓↵ のキーボード操作が主役。 発見性と操作速度は高いが、一時的とはいえ地図中央を覆うため「map center is sacred」とは軽い緊張。focus trap + Esc で離脱。

persistent-pill — 常時表示の検索ピル型

上端中央に検索ピル（frosted rounded-full）を常時アンカー。フォーカスで入力に変わり、下に結果ドロップダウンが下りる。 発見性は最大だが、常設のフォーム的サーフェスが原則4（select-not-fill）と最も摩擦し、standing chrome が 1 つ増える。比較の対極。
