Mobile · M3

領土詳細優先（後勝ち排他、サマリー閉）

利用者が地図上の領土をタップ、またはサマリー内のリンクをタップすると、領土詳細パネルが bottom-sheet として開き、サマリーは完全に閉じる。 v2 の変更点: ドラッグハンドル直下に「1500 年の世界を見る」遷移帯が常時表示され、1 タップでサマリーへ戻れる。

v2 で変更した点

  • 後勝ち排他をデバイス間で統一: v1 の「デスクトップは並列共存／モバイルは後勝ち排他」を廃止し、デバイスを問わず後勝ち排他に統一。 領土詳細パネルが開くとサマリーは完全に閉じる。状態数が減り、操作モデルが一貫する。
  • パネル内遷移帯（中立文言、常時表示）: 領土詳細パネルの上端に「1500 年の世界を見る」帯を常時表示。 遷移元（サマリー / 地図）に依存しない中立文言とすることで、状態管理が単純になり、利用者から見て文言が変動しない。 「←」記号は使わず、サマリートリガーと同じ list アイコンで「サマリー側に切り替える」意図を表現。
  • 閉じるボタンの位置（最右上）: 遷移帯と同じ行の右端に閉じるボタン（×）を配置。dialog / sheet の慣習（パネル右上 = 閉じる）に従い、利用者の認知負荷を下げる。 遷移帯（テキスト＋アイコン、横長）と × （単独アイコン、固定幅）はサイズと形で視覚階層が分離され、役割の混同を防ぐ。 タイトル行からは × を取り除き、上端 1 行を「操作領域」、本文を「コンテンツ領域」と階層を整理。
  • spec への波及: spec FR-006「デスクトップ：両パネルは並列で同時表示可能」を「全デバイスで後勝ち排他」へ変更する必要あり。 FR-009 の「参照リンク → 詳細表示」の体験は、遷移帯と組み合わせることで「サマリー → 詳細 → サマリー」の往復が ボタン 1 タップで完結する。

スタイル整合性

  • 遷移帯は既存トーン（text-gray-300 hover:bg-gray-600/50）のみで構成。装飾追加なし。
  • list アイコン SVG は既存の summary トリガーと同一の path を使用し、視覚的なつながりを担保。
  • role="dialog" + aria-labelledby + 閉じるボタン aria-label は v1 と同様。遷移帯ボタンは focus-visible:ring-2 でキーボードフォーカスが視認可能。
