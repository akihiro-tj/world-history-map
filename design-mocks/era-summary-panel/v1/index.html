年代サマリーパネル

選択中の年代における世界全体の概況を地域別カードで俯瞰する新パネル。既存の地図 + 領土詳細パネル （territory-info-panel）と並列または排他で動作する。本ページではデスクトップ 3 状態 + モバイル 3 状態の合計 6 状態を比較する。

Desktop · D1

初期状態（パネル開、territory-info-panel 閉）

1280 × 800 — デスクトップでは年代サマリーパネルが開いた状態でスタートし、利用者は即座に 「同時代の世界」を俯瞰できる。地図上の領土はまだ選択されていない。

Desktop · D2

並列共存（サマリー + 領土詳細パネル）

サマリーパネルを左、領土詳細パネル（territory-info-panel）を右に並列表示。利用者は俯瞰と詳細を同時に参照できる。 両パネルは同じスタイル言語で揃え、横並びで違和感なく成立する。

Desktop · D3

サマリーパネル閉

利用者が明示的にサマリーを閉じた状態。地図領域がほぼ全面に広がり、左上に「サマリーを開く」トリガーが残る。

Mobile · M1

初期状態（サマリー閉）

375 × 667 — モバイルでは初期状態でサマリーパネルが閉じており、地図領域を最大化する。右下にサマリー開閉トリガー（FAB 風ボタン）が常駐する。

Mobile · M2

サマリーパネル開（bottom-sheet）

利用者がトリガーをタップするとサマリーが bottom-sheet として立ち上がり、画面下半分から地域別カードを表示する。 上端のドラッグハンドルで折りたたみ／展開を操作できる（既存 bottom-sheet コンポーネントを踏襲）。

Mobile · M3

領土詳細優先（後勝ち排他、サマリー閉）

利用者が地図上の領土をタップすると、領土詳細パネルが bottom-sheet として開き、サマリーパネルは完全に閉じる。 再表示は右下のサマリートリガーから明示的に行う。

設計メモ

  • スタイル言語： 既存 territory-info-panel （bg-gray-700/95 + backdrop-blur-sm）を完全に踏襲し、新規装飾は加えない。
  • レイアウト： デスクトップ並列時はサマリーを左、territory-info-panel を右（control-bar の下）に配置することを提案。 位置の最終決定は plan フェーズで行う。
  • トリガー： パネル閉時は同じ位置にラベル付きトリガーボタンを残し、開閉の往復が低コストで行えるよう保証する。 絵文字ではなく SVG アイコン（list 系）を使用。
  • 参照リンク： サマリー本文中の領土名・年代は下線付きリンクとして表示し、クリックで地図フォーカス／詳細表示／年代切替へ遷移できることを示唆。 spec FR-009 に基づき任意で含める。
  • a11y： role="dialog", 閉じるボタンの aria-label を全パネルで担保。spec FR-010 の最低ラインを満たす。
