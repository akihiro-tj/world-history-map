# 都市データの作成方針

- 都市の追加や、名前・読み・座標の変更は、出典付きの案を示してユーザーの承認を得てから入れる
- 正確性を網羅性より優先する。不確かなものは載せない
- 座標は遺跡や歴史的中心地を指す。現在の同名都市の中心とずれるなら遺跡を優先する（例: カラコルムはハルホリン近郊の遺跡、サライはセリトレンノエ付近）。案を示す前に地図（OpenStreetMap など）で位置を確かめる
- 出典は Wikipedia の座標表記や学術資料を使う。座標の精度は小数 2〜4 桁でよい

## 座標の調べ方

- 先に何を指す点にするか（遺跡・都城・現在の都市）を決め、それ自体を扱う記事・項目を探す。同じ都市でも、記事によっては現在の市の座標が載っているため
- ja・en の Wikipedia と Wikidata（P625）の座標を比べる。Wikidata は索引と照合に使い、決め手は記事本文の記述（その座標が何の位置か）にする。Wikidata の座標には出典がないことが多い
- 出典どうしが 20 km 以上離れる、または点が現在の町の中心に重なるなら、OSM で位置を見て理由を確かめる
- 遺跡の位置が分からないとき、近い別の地物（廟など）で代用するなら、何の位置かを案に書く。決められなければ載せない
- source には採った座標が載っている記事の URL を書く。リダイレクトや曖昧さ回避のページは、座標の出どころにならない
