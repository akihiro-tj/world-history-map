# バグ報告 (bug)

本文の骨格は `.github/ISSUE_TEMPLATE/bug.md` を正本とする。

## 収集する情報

発言から埋まらない項目だけを聞く。

1. **何が起きたか** — 観測された挙動（必須）
2. **期待される挙動** — 本来どうあるべきか（必須）
3. **再現手順** — 再現できる場合のみ（任意）

## 深掘り

コードベースを調査し、原因の仮説や影響範囲を簡潔に共有する。追加情報がないか確認する。

## タイトル

「〜できない」「〜が誤っている」など、症状を簡潔に表す。
例: 「年代スライダーで紀元前の年が正しく表示されない」
