# 機能提案 (proposal)

本文の骨格は `.github/ISSUE_TEMPLATE/proposal.md` を正本とする。

## 収集する情報

発言から埋まらない項目だけを聞く。

1. **誰が** — ユーザーの役割（デフォルト: 地図の利用者）
2. **何を** — 実現したいこと（必須）
3. **なぜ** — なぜそれが必要か（必須）
4. **解決策** — 具体的な解決策の案（任意。深掘りで補える）

## 深掘り

収集した情報をもとに、コードベースや既存機能の文脈を踏まえて 2〜3 個に絞って提案する。

提案の観点:
- ユーザーの案をより良くする改善案やアプローチの選択肢
- 一緒に検討すると良い関連機能
- ユーザーが見落としていそうな考慮点

採用された提案は本文の「提案する解決策」に反映する。

## タイトル

機能を動詞形で簡潔に表す。
例: 「年表の表示をタイムライン UI に変更する」「領土クリック時に詳細情報を表示する」
