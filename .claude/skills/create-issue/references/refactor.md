# リファクタリング提案 (refactor)

本文の骨格は `.github/ISSUE_TEMPLATE/refactor.md` を正本とする。

## 収集する情報

発言から埋まらない項目だけを聞く。

1. **対象** — リファクタリング対象のコード・モジュール（必須）
2. **現状の問題** — 今の何が問題か（必須）
3. **改善の方向性** — どうなっていると良いか（任意。Claude が提案してもよい）

## 深掘り

対象コードを実際に読み、具体的なリファクタリング方針を 2〜3 個に絞って提案する。

提案の観点:
- 設計パターンの適用
- 責務の分離・モジュール構成の改善
- 型安全性の向上
- テスタビリティの改善

## タイトル

「〜をリファクタリングする」「〜の責務を分離する」など、改善内容を簡潔に表す。
例: 「map-store の状態管理ロジックを hooks に分離する」
